# 图片生成节点

根据提示词生成图片，也可使用已有图片和文本作为参考，制作角色、场景或分镜图。

## 输入与输出

- 输入支持图片和文本；连接的文本会作为生成要求的一部分。
- 输出一张生成图片，可继续用作图片或视频生成的参考。

## 使用方法

1. 选中节点，在下方选择图片模型；没有模型时先在设置中添加图片模型。
2. 输入画面要求，按需连接图片或文本参考，并在提示词中引用它们。
   缩略图上方的“上传”支持本地图片和素材库素材；“画布参考”可直接点选画布图片并连线，按 Esc 或“返回节点”取消选择并回到原节点视角。
3. 点击比例与分辨率区域，选择当前模型提供的选项。
4. 点击“生成图片”；生成过程中可点击“停止生成”。
5. 完成后在节点内查看结果，左键双击图片可放大预览；选中节点可从上方下载，工具栏最右侧按钮用于聚焦节点。
6. 选中节点后，点击图片右上角的历史记录图标，展开缩略图列表；点击条目切换图片，当前图片会标记「当前」，每项右侧的放大按钮可单独预览该图片。
7. 历史图标左侧的“替换素材”可选择本地上传或当前画布中的图片。

放大预览时，按住鼠标中键（滚轮键）拖动图片，滚动滚轮缩放；左键双击图片恢复完整适应窗口，并重置位移和旋转。

工具栏“标记”前的“旋转与镜像”会在旁边新建并连接图片节点，支持自定义角度、顺时针旋转 90°、水平及垂直镜像，保存为独立 PNG 图片。

查询或下载中断时，节点下方显示「复查任务」「取回结果」或「显示结果」，沿用原任务编号或已保存的图片地址，不重新生成。没有恢复凭据或明确失败时可点击「查看详情」。停止等待后，仍有凭据的本地供应商任务可手动取回；开始新任务后入口指向新任务，旧结果不会自动覆盖它。

参考素材可在输入区调整顺序或移除。连接的节点需要已有内容，修改提示词或设置后需再次点击生成才会产生新图片。
