# 图片节点

在画布中展示图片，可作为角色、场景、道具或分镜参考。

## 输入与输出

- 导入本地图片文件，单个文件不能为空且不超过 100 MB。
- 输出当前图片素材，可连接图片生成、视频生成等支持图片输入的节点。

## 使用方法

1. 点击上传按钮，选择图片文件。
2. 上传完成后，节点按图片比例显示预览。
3. 将图片输出连接到需要参考图的节点。
4. 左键双击节点图片可放大预览；选中节点后，使用顶部工具栏下载或替换图片，最右侧按钮用于聚焦节点。

放大预览时，按住鼠标中键（滚轮键）拖动图片，滚动滚轮缩放；左键双击图片恢复完整适应窗口，并重置位移和旋转。

工具栏“标记”前的“旋转与镜像”会新建并连接一个图片节点，可输入角度、顺时针旋转 90°、水平或垂直镜像。点击保存后将结果存为独立 PNG；退出则保留新节点中的原图。编辑草稿随画布保存，旋转后空出的区域保持透明。
