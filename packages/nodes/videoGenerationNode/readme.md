# 视频生成节点

根据提示词和参考素材生成视频，支持所选模型提供的文生视频、单图、首尾帧或全能参考模式。

## 输入与输出

- 输入支持文本、图片、视频和音频，实际可用的素材组合取决于模型与生成模式。
- 输出生成的视频；播放器还能将当前帧、首帧或尾帧截取为图片节点。

## 使用方法

1. 选中节点，选择视频模型；没有模型时先在设置中添加视频模型。
2. 输入动作、运镜和声音要求，按需连接参考素材并调整引用顺序。
   缩略图上方的“上传”支持本地图片和素材库素材；“画布参考”可点选画布图片并连线，按 Esc 或“返回节点”取消选择并回到原节点视角。
3. 打开生成设置，选择模式、时长、分辨率和画面比例；模型允许时可切换“生成音频”。
   模式可手动切换，连接或断开素材不会改回已选模式。文生视频将媒体缩略图置灰，保留连线但不发送媒体素材，切回参考模式后恢复；参考模式缺少素材或数量不符合要求时，会在生成前提示。提示词中显式引用的媒体须移除引用或改用参考模式。
4. 使用首尾帧模式时，图片按引用顺序分配；“首帧可选”模式仅有一张图片时，该图片作为尾帧。
5. 点击“生成视频”，需要中止时点击“停止生成”。
6. 完成后可播放、拖动进度、调整音量，左键双击视频画面进入全屏预览；顶部工具条最右侧的定位按钮用于聚焦节点。
7. 选中节点后，点击视频右上角的历史记录图标，可查看缩略图、切换当前视频，或单独放大播放历史视频。

截帧需要启用图片节点。时长与分辨率选项随模型变化，通用画面比例的实际支持范围由供应商决定。

结果查询或下载中断时，使用节点下方的「复查任务／取回结果」继续取回原任务；缺少恢复凭据时可查看详情。停止等待不等于供应商撤销任务，有凭据的本地任务仍可手动取回，不自动重新生成，也不覆盖后来替换的输出。
