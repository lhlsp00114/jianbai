# 脚本生成器

独立的脚本节点，参考 LibTV 脚本节点的三阶段制作流程：确认镜头、准备角色／场景／道具资产、合成提示词。支持剧本拆解、角色图片参考创作和手工编写；分镜可编辑、标记行颜色和移除。通过节点右侧的文本输出及上方下载按钮导出分镜脚本。

AI 使用宿主已有语言模型和文本／图片参考接口。模型返回通过结构、长度、名称唯一性和资产关联校验后才应用；失败或取消保留原分镜及已收到的返回内容，不自动重试。角色模式需要连接图片，所选语言模型必须支持图片理解。新节点不自动调用付费模型。

三阶段编辑器支持维护镜头时长、画面、景别、光影、对白旁白、声音、运镜和资产关联。合成提示词是本地操作；再次合成会询问是否覆盖已编辑提示词。修改分镜或资产后需重新合成，再创建下游节点。

资产与分镜可批量创建现有图片生成节点；视频优先连接已完成的分镜图，否则使用该镜头关联的资产图片。生成配置与任务管理沿用现有节点，模型不支持的比例、时长会报错，不擅自替换。勾选“同时启动生成”并确认费用提示后才提交媒体请求；创建完成不代表媒体生成完成。

相同配置沿用关联节点，已有结果、运行中或待确认任务不重复付费提交；已确认失败或取消的任务可在用户再次启动生成时重试。提示词或参考配置改变时创建新版本，保留旧节点和素材。停止只停止脚本拆解或尚未启动的队列；已提交的媒体任务由对应节点管理，不承诺供应商撤销费用。

数据保存在原有画布的 node.data.scriptDocument 中，复用画布保存与历史批处理；此插件不删除磁盘素材、OSS 或数据库内容。批量创建为一次画布结构历史，脚本内部编辑与既有画布历史的内容边界一致，不冒充结构撤销。

构建：bun run --filter '@toonflow/node-script-generator' build --mode development。开发产物同步到 data/nodes/scriptGeneratorNode.umd.js，通过现有插件加载流程发现。类型检查使用本包已有 typecheck 命令。不新增独立服务或测试模块。
